# Политика конфиденциальности — «Взмах» (Vzmah)

Последнее обновление: 14 октября 2026 г.

Приложение «Взмах» — Bluetooth HID-пульт для презентаций. Разработчик:
Сергей Каманов.

## Коротко

Приложение **полностью работает офлайн**. Оно не собирает, не передаёт и
не хранит персональные данные пользователей на стороне разработчика.

## Отсутствие доступа к сети

В `AndroidManifest.xml` приложения **не запрошено разрешение
`android.permission.INTERNET`**. Это означает, что приложение физически не
имеет возможности отправлять какие-либо данные по сети — ни на сервер
разработчика, ни к третьим сторонам.

## Что приложение не делает

- Не содержит систем аналитики, рекламы, отслеживания или краш-репортов.
- Не использует сторонние SDK.
- Не запрашивает доступ к контактам, файлам, медиа, геолокации, аккаунтам,
  состоянию телефона или журналу звонков.
- Не продаёт и не передаёт данные третьим лицам.

## Какие разрешения использует приложение и зачем

| Разрешение | Зачем |
| --- | --- |
| `BLUETOOTH`, `BLUETOOTH_ADMIN` (до Android 12) | Поиск и подключение к ПК |
| `BLUETOOTH_CONNECT` | Подключение к ПК и передача команд |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_CONNECTED_DEVICE` | Фоновая работа пульта во время презентации |
| `POST_NOTIFICATIONS` | Уведомление о работе службы |
| `VIBRATION` | Отклик вибрацией на команды |
| `WAKE_LOCK` | Не дать устройству уснуть во время презентации |

Датчики движения (акселерометр/гироскоп) используются только для жестов и
работают в памяти процесса — данные никуда не сохраняются и не передаются.

## Что хранится локально на вашем устройстве

Приложение сохраняет настройки и историю подключений в локальном хранилище
приложения (`SharedPreferences`) — эти данные не покидают ваше устройство:

- **`vzmah_ui`** — настройки интерфейса: скорость курсора и прокрутки,
  пресет указателя, инверсия оси Y, вибрация, «жест — следующий слайд»,
  фоновый режим, отметка о показанной подсказке.
- **`vzmah_hid`** — запоминание ранее подключённых Bluetooth-устройств
  (MAC-адрес и имя хоста), чтобы переподключение не требовало повторного
  сопряжения.

## Bluetooth

Команды (клавиши, мышь, прокрутка) передаются по Bluetooth HID
**напрямую на подключённый вами компьютер**. Данные не проходят через
серверы разработчика. Настройки, передаваемые на компьютер (например,
раскладка клавиатуры), обрабатываются операционной системой компьютера.

## Удаление данных

Чтобы удалить все локальные данные приложения:

1. Откройте «Настройки Android» → «Приложения» → «Взмах».
2. «Хранилище и кэш» → «Очистить данные».

Дополнительно отвяжите профиль Bluetooth HID на компьютере, если он больше
не нужен.

## Дети

Приложение не предназначено для сбора данных о детях и таких данных не
собирает.
